# Đánh giá BCSD — Dương/c4

**Kết luận:** `YES`

## High-level code tương ứng

```c
Record *register_record(Record *record)
{
    if (table == NULL) {
        table = allocate_table(initial_capacity);
        table_size = 1;
        initialize_first_slot(table);
    } else if (table_size - 1 <= current_index) {
        table = grow_table(table, table_size + 8);
        clear_new_slots(table, table_size);
        table_size += 8;
    }

    Record **slot = &table[current_index];
    if (*slot == record)
        return record;

    if (*slot != NULL)
        restore_cached_fields_from_previous(*slot);

    if (record != NULL) {
        *slot = record;
        update_global_cache_from_record(record);
    }

    return cached_record_field;
}
```

Hàm quản lý một bảng record toàn cục tại `current_index`. Nó khởi tạo hoặc mở
rộng bảng khi thiếu chỗ, trả về sớm nếu record mới trùng record đang ở slot,
khôi phục các trường cache của record cũ, rồi gắn record mới và cập nhật cache
toàn cục từ record đó. Các global cụ thể là dữ liệu trạng thái của thư viện,
không làm thay đổi cấu trúc logic này.

## Mapping giữa hai target và high-level code

### Target 1 — `sub_26214`

- `dword_724AC` → `table`.
- `dword_724B0` → `table_size`/capacity; `dword_724B4` → `current_index`.
- `sub_4F9A0(4)` → cấp phát bảng ban đầu; `sub_4F9B8(...)` → mở rộng bảng.
- `memset(v2 + 4 * dword_724B0, 0, 0x20)` → xóa vùng slot mới.
- `v2 + 4 * v3` → địa chỉ `slot`.
- `*(v2 + 4 * v3)` → `*slot`, record cũ.
- `v1`/`result` → `record`.
- Các phép ghi qua `dword_724B8`, `dword_724C0`, `dword_724C4`, `byte_724BC`
  → `restore_cached_fields_from_previous` và `update_global_cache_from_record`.

### Target 2 — `sub_416150`

- `qword_46B7B8` → `table`; `qword_46B7E0` → capacity;
  `qword_46B7C0` → `current_index`.
- `sub_43E3F8(8)`/`sub_43E408()` → cấp phát/mở rộng bảng.
- `result + 8 * index` → địa chỉ slot; `*v2` → record cũ.
- `a1` → `record`; `*slot == a1` → kiểm tra record trùng.
- `qword_46B7C8`, `byte_46B7E8`, `dword_46B7EC`, `qword_46C550` và
  `qword_46B7F0` → cache tương ứng với các global ở target 1.

## Khác biệt nhỏ

Target 1 là ARM 32-bit, dùng slot 4 byte và cấp phát block 32 byte; target 2 là
ARM 64-bit, dùng slot 8 byte và cấp phát block lớn hơn. Tên global, offset field
(`+4`/`+2` so với `+16`/`+28`) và helper cấp phát khác nhau do layout pointer và
kiến trúc. Hai hàm vẫn có cùng trình tự khởi tạo bảng, kiểm tra record trùng,
khôi phục cache, gán slot và cập nhật cache.
