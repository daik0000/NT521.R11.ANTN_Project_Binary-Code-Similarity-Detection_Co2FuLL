**Cặp tương ứng:** c9 trong `tmp`

## Target 1 — `sub_7267C`

### High-level code

```c
int handle_error(const char *format, va_list arguments)
{
    scan_format_and_argument_types(format, types);
    load_arguments(arguments, types);
    print_prefix_and_formatted_message(format, types, stderr);
    flush_streams();
    return error_output_status();
}
```

Hàm gồm hai phần: scan format để xác định kiểu đối số, sau đó lấy đối số,
format thông báo lỗi và ghi ra `stderr`.

### Mapping

- `a1` → format string.
- `a2` → danh sách đối số.
- Bảng kiểu → loại conversion của từng đối số.
- `fprintf`/`fputc` → output thông báo.
- `fflush` → flush các stream.
- Giá trị trả về → trạng thái thao tác output.

## Target 2 — `sub_805A5C0`

### High-level code

```c
unsigned int scan_format(const char *format, TypeInfo *types)
{
    unsigned int argument_count = 0;

    while (*format != 0) {
        if (is_conversion(format)) {
            types[argument_count] =
                identify_conversion_type(format);
            ++argument_count;
        }
        format = next_character_or_conversion(format);
    }

    return argument_count;
}
```

Hàm chỉ phân tích format string, ghi loại conversion vào bảng và trả về số
conversion/đối số. Hàm không lấy đối số thực tế và không ghi thông báo lỗi.

### Mapping

- `a1` → format string.
- `a2` → bảng kiểu đối số.
- Các nhánh parse → flags, width, precision, length modifier và conversion.
- Giá trị trả về → số conversion đã phát hiện.
- Không có các lời gọi output hoặc flush stream.

## Vì sao BCSD là NO

Target 2 chỉ thực hiện phase scan format nằm trong Target 1. Target 1 còn có
load argument, error handling, output ra `stderr` và flush stream. Một hàm
chứa thêm toàn bộ các hành động quan sát được của phase sau không thể được xem
là cùng logic với scanner độc lập.

## Giải thích lỗi của LLM

LLM nhìn thấy hai hàm cùng xử lý format specifier, width, precision và kiểu
đối số nên kết luận cùng core algorithm. Sai lầm là đồng nhất một phase chung
với toàn bộ control flow và side effect của hai hàm.
